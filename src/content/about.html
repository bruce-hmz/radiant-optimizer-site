Radiant Optimizer List is an independent directory of classic games that run in a browser tab. It started from a graphic and a links reply posted by @RadiantOpti on 8 October 2026, and it also keeps a wider library of similar projects that were not on that graphic.

Not the Radiant Optimizer product

This site does not sell, license or support Radiant Optimizer. That name belongs to a separate Windows tuning tool. Buying the tool does not unlock the games here, and the games do not require the tool. The product's own site is radiantoptimizer.com.

What this site does

  • Lists each project with its real destination, a screenshot when we could capture one, and what it needs before it will run.
  • Separates the original @RadiantOpti list from the wider library, so the two are not mixed together.
  • Says plainly when a link is an archive, a mismatch, or something we could not verify.

What this site does not do

  • We do not host, mirror or provide game files, and we do not offer copies of commercial games.
  • We are not affiliated with the projects listed, their authors, or the original publishers.
  • We do not operate the game hosts. If a project is down, only that host can bring it back.

How to read an entry

Start with how to use the list if you want the short version of the badges, or is it safe? before you open an unfamiliar host. The original list is on the homepage. The full library is a separate page.

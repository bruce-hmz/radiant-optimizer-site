Most problems with these browser projects are not your fault, and they are not your PC's fault either. They come from the host: a missing file, a busy server, an unsupported browser feature, or a link that has moved. Work through the symptoms below in order and you will usually find the cause within a minute.

Symptom-to-cause table

What you seeMost likely causeWhat to do
A file picker or a request for game dataThe project needs data from a game you ownConfirm the exact edition and archive format. A console image, a PC folder and a save file are not interchangeable.
An "unsupported graphics" or browser messageThe host needs a feature your browser does not exposeRead the exact feature the host names, then check its supported-browser list. A tuning utility does not add browser graphics support.
The download stops, or you get a blank canvasA server-side problem or a stalled asset loadKeep the URL and any message, check the host's status or help page, and try again later. Do not infer the cause from a blank screen alone.
A certificate warningThe host's TLS certificate does not match the addressStop at the warning. Never bypass it. Return to the project's announcements for a corrected address.
Mouse or controller does not respondThe project has not captured input focusClick the canvas, check the project's focus and capture settings, and use its documented exit key before switching tabs.
Saved progress disappearsSite data was cleared, or a different browser profile is in useCheck which profile you used and read the project's export or import instructions before clearing any more site data.
The page returns "busy" or a 429 messageThe host is rate limiting requestsWait and retry later. Reloading in a loop usually makes it worse.

If a game will not load at all

  1. Confirm you are on the right address. Several entries in the original list have names that do not match their destination. Compare the project name with the site you actually landed on.
  2. Try a different browser. Some ports need features that are only enabled in certain browsers. This is a project limitation, not something you can install your way around.
  3. Give the loader time. A 380 MB first load is normal for at least one entry here. Closing the tab mid-load is the most common self-inflicted failure.
  4. Check for a status page. If the project has one, it will tell you more in ten seconds than a support email will in a day.

Two things you should never do

Do not bypass a certificate warning, and do not download an unfamiliar executable to play something advertised as a browser-only game. Both are the classic routes to a real infection.

Reporting a broken entry

If a link on this site is dead or points somewhere unexpected, note the project name, the host address and the exact error, then use the corrections page. We can correct our directory; only the project operator can fix their own service.

This is a static directory, not a support desk. Where you should go depends on what is broken.

A page on this site is wrong

If a destination, status note or screenshot on Radiant Optimizer List is out of date, send a correction with:

  • The page URL on this site
  • The project name
  • The host address you expected, and what you saw instead

Corrections are tracked in the public repository: github.com/bruce-hmz/radiant-optimizer-site/issues. There is no separate email inbox for this site.

A game will not load

We do not run the game hosts. Read what to do when a game will not load, then use that project's own help or status page. We can correct our link. We cannot restart their server.

Radiant Optimizer, the Windows tool

Purchases, refunds, licences and the product itself are handled by the seller, not by this directory. Use the official site: radiantoptimizer.com.

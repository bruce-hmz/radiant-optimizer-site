How to use the browser games list

A plain-English walkthrough of the list shared by @RadiantOpti: what the four entry types mean and how to start a first session safely.

What the list actually is

On 8 October 2026 the Radiant Optimizer account on X (@RadiantOpti) posted a graphic of classic games that run in a browser tab, followed by a reply with the project links. The graphic is a menu, not a download. Every game on it runs on someone else's website, built by a fan or an independent developer.

That distinction matters more than anything else on this page. Radiant Optimizer is a Windows tuning utility. The browser games are separate community projects that the account happened to share. Buying the utility does not unlock the games, and the games do not require the utility.

Check the destination and requirements

A browser project can be a demo, a multiplayer port, a fan adaptation or a setup screen that asks for your own game files. The requirement badge says what the listing says you need; the project status note records available evidence about the destination. Neither is proof that gameplay works.

The four kinds of entry you will meet

Sorting the list by what each project needs is the fastest way to avoid disappointment. Almost every entry falls into one of four buckets.

No extra files listed

The listing does not identify extra game files or an installer as a requirement. This badge does not mean the destination is reachable or that gameplay was verified.

Check setup first

The listing leaves requirements or setup unclear. Check the project notes only when the destination link is available; a network response alone does not prove a game loads.

Bring your own game files

The project expects data converted from a game you legally own. Browser access does not include those files, and we do not provide them.

Archive or unavailable

An archive is historical evidence. An unavailable entry has no launch link. Neither label promises a playable destination today.

Your first session, step by step

  1. Pick an entry and compare its requirement with its status evidence. The badge describes setup or files; the separate note describes what is known about the destination. If a link is disabled, mismatched or has a certificate warning, do not open or force it.
  2. Prepare the device. Use the browser and input devices the project documents. A desktop-only build will not magically support touch, and a mobile build is not a promise that every phone works.
  3. Allow time for data. Browser play can still transfer a large amount of game data. Read the loader and storage prompt, and avoid reloading repeatedly while progress is advancing.
  4. Check controls and saving. Find the project's help or settings screen. Before a long session, check whether progress can be exported and whether clearing site data would erase it.

Why these games carry the Radiant name

They do not, really. The name comes from the account that shared the list. Our directory follows the original reply so you can compare the names in the graphic with the destinations, which do not always match. The Skate Rust entry has a destination mismatch, and the Moon Zombies, Kino der Toten and BO3 Cheese Cube links are disabled because their page responses contained off-topic navigation hints. The hints were not followed. Their detail pages preserve the list entries and explain the current status.

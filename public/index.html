How to read the badges

The badges describe listed setup and file requirements. A separate project status note records what is known about each destination; it does not certify gameplay.

No extra files listed

No extra game files or installer are listed as requirements. The destination may still be unavailable, and gameplay is not implied.

Check setup first

Requirements or setup need checking. Use project instructions only if its destination is available.

Bring your own files

Expects data converted from a game you legally own. Browser access does not include those files.

Archive snapshot Link withheld

An archive is historical context; an unavailable entry has no launch link. Neither indicates current gameplay.

How to read the badges

The fastest way to avoid disappointment is to check what a project needs before you click. Every entry falls into one of these buckets.

Ready to start

The host lists a browser start. Quickest to try, still a community project with no uptime guarantee.

Check setup first

The project loads, but read its own notes for controls, servers or data before committing a session.

Bring your own files

Expects data converted from a game you legally own. Browser access does not include those files.

Archive snapshot Link withheld

The link resolves to an archive or fails a check. Historical context rather than something playable today.

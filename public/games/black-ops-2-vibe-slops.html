Black Ops 2 / Vibe Slops

The project the original list labels as Black Ops 2, actually named Vibe Slops.

The destination was not readable during our check, so content is unconfirmed.

What it is

The shared list names this entry Black Ops 2, but the community project behind it is called Claude of Duty: Vibe Slops II. It is an independent build, so do not expect the full original game.

What you need

  • A desktop browser
  • A stable connection
  • The understanding that this is a fan build with its own content

How to open it

  1. Open the source destination from this page.
  2. Wait for the project to initialise.
  3. Read the project's own notes before judging what is included.

Before you click

We link to the original destination only and we do not host or provide game files. If the project asks for data, use files from a game you legally own. Never bypass a certificate warning and never install an unfamiliar executable to play a browser game.

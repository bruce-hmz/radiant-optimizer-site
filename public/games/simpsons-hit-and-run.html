The Simpsons: Hit & Run

A community web port of Springfield's driving adventure.

What it is

A fan project that ports The Simpsons: Hit & Run to the browser. A loading screen was found during the check, but a running scene and the controls were not tested.

What you need

  • A desktop browser
  • A stable connection for the initial load
  • A keyboard or gamepad for driving

How to open it

  1. Open the source destination from this page.
  2. Allow the loading screen to finish.
  3. Read the project's page for controls and any data requirements.

Before you click

We link to the original destination only and we do not host or provide game files. If the project asks for data, use files from a game you legally own. Never bypass a certificate warning and never install an unfamiliar executable to play a browser game.

GoldenEye 007

The N64 split-screen shooter legend, rebuilt to run in a browser.

Open project page ↗ Back to the original list

Verification status

Checked Oct 11, 2026; HTTP response 200. Gameplay not tested.

Project status / evidence: Clean-room browser build of the N64 original, hosted by Decomp Games. Not affiliated with the original publishers.

What it is

GoldenEye 007 is Rare's 1997 N64 shooter, built around the 1995 film and known for its four-player split-screen multiplayer and its stealth-or-firefight mission design. This browser build runs from the community decompilation rather than a ROM emulator, so it is the reconstructed engine rather than a dumped cartridge, and the default controls are the project's own.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser with WebGL
  • A keyboard and mouse, or a gamepad
  • A modern browser, since the build targets current WebGL features

How to open it

  1. Open the GoldenEye 007 build on Decomp Games.
  2. Wait for the loader to finish.
  3. Check the control scheme before a mission, as the default binds are not the N64 layout.

Freedoom

A completely free Doom-engine game with its own art and levels.

Open project page ↗ Back to the original list

Verification status

Checked Oct 11, 2026; HTTP response 200. Gameplay not tested.

Project status / evidence: Free and open-source assets throughout, hosted by Decomp Games. No commercial files required.

What it is

Freedoom is a free, open-source game built on the Doom engine with entirely original art, sound and levels, so nothing is borrowed from the commercial release. That makes it the cleanest way to play a Doom-style game in a browser, and it remains compatible with the same source ports as the original. It ships as two replacement episodes for the classic campaigns.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser
  • A keyboard and mouse
  • Nothing else, since every asset is free and included

How to open it

  1. Open the Freedoom build on Decomp Games.
  2. Click the canvas to capture input.
  3. Check the in-game menu for controls, then choose a difficulty.

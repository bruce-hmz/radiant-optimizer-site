SuperTuxKart (Wasm)

The open-source kart racer, compiled to run in a browser tab.

Open project page ↗ Back to the original list

Verification status

Checked Oct 11, 2026; HTTP response 200. Gameplay not tested.

Project status / evidence: Experimental WebAssembly port. Rendering APIs and networking are incomplete, and the initial download is 120 MB or more.

What it is

SuperTuxKart is the long-running open-source kart racer, and this is an experimental WebAssembly port of it. The port's author reports that everything works except some rendering APIs and networking, so expect single-player racing rather than online play. It is the heaviest entry in this library: the low-quality texture set alone is a 120 MB download, the high set is 249 MB, and the game asks for roughly 500 MB of memory, which makes it a poor fit for a low-end machine or a slow connection.

Requirement

Check setup first Check the project-specific setup information if the destination is available; requirements may still be unknown.

What you need

  • A desktop browser with WebAssembly support
  • Bandwidth for a 120 MB or larger initial download
  • Around 500 MB of free memory

How to open it

  1. Open the SuperTuxKart Wasm page.
  2. Choose a texture quality: low is 120 MB, medium 171 MB, high 249 MB.
  3. Press Start Game and let the download finish before expecting a menu.

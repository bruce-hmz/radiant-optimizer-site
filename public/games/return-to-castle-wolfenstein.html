Return to Castle Wolfenstein

A community RTCW project with multiplayer and a sizable first load.

Open the original project ↗ Back to directory

The host describes multiplayer and roughly a 380 MB initial load.

What it is

Return to Castle Wolfenstein is the 2001 shooter that rebuilt the Wolfenstein series in full 3D, and it leaned heavily on its class-based multiplayer. The host describes multiplayer and an initial data load of roughly 380 MB; campaign play was not established, so expect a multiplayer-focused build.

What you need

  • A desktop browser
  • Enough bandwidth and patience for a large first load
  • A keyboard and mouse

How to open it

  1. Open the source destination from this page.
  2. Let the initial data load finish without reloading.
  3. Check the host's notes for servers and controls.

Before you click

We link to the original destination only and we do not host or provide game files. If the project asks for data, use files from a game you legally own. Never bypass a certificate warning and never install an unfamiliar executable to play a browser game.

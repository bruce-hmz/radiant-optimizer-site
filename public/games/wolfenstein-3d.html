Wolfenstein 3D

The original 1992 first-person shooter, running in a browser tab.

What it is

Wolfenstein 3D is the 1992 shooter that established the first-person genre, built on the engine family that Doom would later extend. This entry runs the DOS build through browser emulation with no installation, and the level layouts are the original ones rather than a modern remake. There is no mouse look, so expect the period control scheme.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser
  • A keyboard
  • A click on the canvas to capture input

How to open it

  1. Open the Wolfenstein 3D page on DOS Zone.
  2. Wait for the DOS bundle to load, then click the screen to begin.
  3. Use the in-game menu to set difficulty and controls before the first level.

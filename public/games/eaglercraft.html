Eaglercraft

A community-built Minecraft client that runs entirely in a browser tab.

Open project page ↗ Back to the original list

Verification status

Checked Oct 11, 2026; HTTP response 200. Gameplay not tested.

Project status / evidence: Community client with its own bugs and version quirks. Not affiliated with Mojang or Microsoft.

What it is

Eaglercraft is a long-running community project that reimplements a Minecraft client so it runs inside a single browser page, including a form of multiplayer. It has existed for years and is packaged as one page rather than an install. It is a fan client with its own quirks and bugs, and it is not affiliated with Mojang or Microsoft.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser
  • A stable connection if you want to join community servers
  • Acceptance that this is a fan client, not an official release

How to open it

  1. Open the Eaglercraft play page.
  2. Choose a version from the list, then start a single-player world or open the server list.
  3. Read the project's own notes for controls and server rules.

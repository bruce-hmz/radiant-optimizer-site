Super Mario 64 (sm64js)

A JavaScript WebGL port of Super Mario 64 built from the decompilation.

Open project page ↗ Back to the original list

Verification status

Checked Oct 11, 2026; HTTP response 200. Gameplay not tested.

Project status / evidence: Community port built from the Super Mario 64 decompilation. Not affiliated with Nintendo.

What it is

sm64js is a native JavaScript port of Super Mario 64 derived from the community decompilation of the N64 original. It renders through WebGL and keeps the castle hub and the star-collecting structure. Because it is a native port rather than an emulator, performance depends on your browser rather than on emulating N64 hardware.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser with WebGL
  • A keyboard or a USB gamepad
  • Patience while the assets download on the first load

How to open it

  1. Open the sm64js build.
  2. Wait for the asset loader to finish before touching the controls.
  3. Check the project page for the button layout, which is not the N64 original's.

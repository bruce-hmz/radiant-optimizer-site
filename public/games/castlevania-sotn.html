Castlevania: Symphony of the Night

The PlayStation action classic, rebuilt to run in a browser.

Open the original project ↗ Back to the original list

Clean-room browser build of the 1997 PlayStation original, hosted by Decomp Games.

What it is

Castlevania: Symphony of the Night is Konami's 1997 PlayStation title, and it is the game that gave the exploration-focused action format its name by mixing a large map with RPG levelling and equipment. It also hides a second, inverted castle behind the first ending. This build runs from the community decompilation of the PlayStation original.

What you need

  • A desktop browser with WebGL
  • A gamepad is recommended for the combat timing
  • A modern browser

How to open it

  1. Open the Symphony of the Night build on Decomp Games.
  2. Wait for the loader.
  3. Check the controls before you start exploring the castle, since the map is large.

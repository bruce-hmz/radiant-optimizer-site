Mortal Kombat

The 1993 fighting game, running from its DOS build in a browser.

What it is

Mortal Kombat is the 1993 fighting game that made digitised actors and finishing moves famous, and it runs here from the DOS build through a browser DOS environment. The DOS release keeps the original roster and the two-player versus mode, and it is free to play on DOS Zone without registration. One thing to expect before you start: this build opens with the manual-based copy-protection check, the screen that asks for a word from a given page, paragraph, line and word of the printed booklet, so you need the manual or the answer before you reach the character select screen. Virtual controls are provided for touch devices, but a keyboard is the better way to learn the special moves.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser
  • A keyboard, since the special moves need two-handed input
  • The DOS manual, or the answer to the copy-protection word check
  • Patience with the DOS-era key mapping

How to open it

  1. Open the Mortal Kombat page on DOS Zone.
  2. Let the DOS bundle load, then click the screen to capture input.
  3. Clear the copy-protection screen by entering the word it asks for from the manual.
  4. Read the control list before you start, then pick a fighter and a mode.

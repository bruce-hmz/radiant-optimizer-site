Doom & Fan Mods

Project status / evidence: Fan-run collection bundling classic Doom with community conversions. Not an official release.

What it is

A fan-run browser Doom collection that bundles classic Doom with community conversions and themed total conversions built on the same engine. Because the mods vary widely in scope and quality, it is best treated as a launcher to browse than as one curated game. It is a fan collection, not an official release.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser
  • A keyboard and mouse
  • A willingness to experiment, since mod quality varies

How to open it

  1. Open the collection.
  2. Pick a build from the list and note which base game it expects.
  3. Click the canvas to capture input, then check the in-game key bindings.

Before you click

We link to the original destination only and we do not host or provide game files. If the project asks for data, use files from a game you legally own. Never bypass a certificate warning and never install an unfamiliar executable to play a browser game.

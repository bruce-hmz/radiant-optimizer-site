Quake / QuakeWorld

The arena classic rebuilt for browser multiplayer with fast movement.

Open the original project ↗ Back to directory

The destination describes a QuakeWorld multiplayer project and lists a browser start.

What it is

The destination describes a QuakeWorld multiplayer project, so treat it as a fast, competitive multiplayer experience rather than a full single-player campaign.

What you need

  • A desktop browser
  • A keyboard and mouse for the movement binds
  • A stable connection, since this is a live multiplayer project

How to open it

  1. Open the source destination from this page.
  2. Read the mode notes so you know what to expect.
  3. Join a server and check the movement binds before playing seriously.

Before you click

We link to the original destination only and we do not host or provide game files. If the project asks for data, use files from a game you legally own. Never bypass a certificate warning and never install an unfamiliar executable to play a browser game.

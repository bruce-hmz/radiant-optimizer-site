What it is

The destination identifies Diablo Web, a browser port of the original dungeon crawler. Its file requirements were not verified, and it may need data from a copy you own.

What you need

  • A legally owned copy of Diablo if data is required
  • A desktop browser
  • The project's own notes on which files to supply

How to open it

  1. Open the source destination from this page.
  2. Read the project's setup notes for file requirements.
  3. Supply your own data only where the project documents it.

Before you click

We link to the original destination only and we do not host or provide game files. If the project asks for data, use files from a game you legally own. Never bypass a certificate warning and never install an unfamiliar executable to play a browser game.

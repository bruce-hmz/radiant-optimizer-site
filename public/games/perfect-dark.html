Perfect Dark

Rare's N64 shooter, rebuilt from the decompilation to run in a browser.

Open project page ↗ Back to the original list

Verification status

Checked Oct 11, 2026; HTTP response 200. Gameplay not tested.

Project status / evidence: Clean-room browser build of the N64 original, hosted by Decomp Games. Includes the Combat Simulator with bots.

What it is

Perfect Dark is Rare's 2000 N64 follow-up to GoldenEye, a sci-fi shooter starring Joanna Dark. It shipped with a Combat Simulator that supported bots, co-operative missions and a counter-operative mode, which was unusually complete for a console shooter of the era. This build runs from the community decompilation of the N64 original.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser with WebGL
  • A keyboard and mouse or a gamepad
  • Patience for the initial load, which pulls down the level assets

How to open it

  1. Open the Perfect Dark build on Decomp Games.
  2. Let the loader complete.
  3. Read the control notes, then try the Combat Simulator with bots before the campaign.

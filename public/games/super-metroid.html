Super Metroid

The SNES exploration classic, rebuilt to run in a browser.

Open the original project ↗ Back to directory

Clean-room browser build of the 1994 SNES original, hosted by Decomp Games.

What it is

Super Metroid is Nintendo's 1994 SNES title, and it set the template for exploration-driven action adventures: an interconnected map, abilities that unlock new routes and a largely wordless story. It is also famous for rewarding sequence-breaking, so skilled players can reach areas out of order. This build runs from the community decompilation of the SNES original.

What you need

  • A desktop browser
  • A keyboard or gamepad
  • A modern browser, plus the map screen button noted

How to open it

  1. Open the Super Metroid build on Decomp Games.
  2. Wait for the loader.
  3. Check the controls before you leave the first area, and note the map screen button.

Duke Nukem: Zero Hour

The N64 Duke Nukem outing, rebuilt to run in a browser.

Open project page ↗ Back to the original list

Verification status

Checked Oct 11, 2026; HTTP response 200. Gameplay not tested.

Project status / evidence: Clean-room browser build of the N64 title, hosted by Decomp Games. Distinct from the DOS Duke Nukem 3D.

What it is

Duke Nukem: Zero Hour is the 1999 N64 outing, and it differs sharply from the PC Duke games: it is a third-person shooter with a time-travel plot that moves between eras. This build runs from the community decompilation of the N64 version, so it is not the DOS Duke Nukem 3D that most people mean by the name.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser with WebGL
  • A gamepad or keyboard and mouse
  • A modern browser

How to open it

  1. Open the Zero Hour build on Decomp Games.
  2. Let the loader finish.
  3. Read the control notes before starting, since the third-person camera takes adjusting.

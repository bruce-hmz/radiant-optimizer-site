Banjo-Kazooie

The N64 collect-a-thon platformer, rebuilt for the browser.

Open the original project ↗ Back to directory

Clean-room browser build of the N64 collect-a-thon, hosted by Decomp Games.

What it is

Banjo-Kazooie is Rare's 1998 N64 platformer, built around exploration and collection: Jiggies open new worlds and musical Notes gate your progress. The bear-and-bird pairing gives it a move set that expands as you learn new abilities, so later worlds depend on earlier ones. This build runs from the community decompilation of the N64 original.

What you need

  • A desktop browser with WebGL
  • A gamepad or keyboard
  • A modern browser, and the patience for a collect-a-thon

How to open it

  1. Open the Banjo-Kazooie build on Decomp Games.
  2. Wait for the loader.
  3. Check the controls before leaving the first world, since the move list grows as you play.

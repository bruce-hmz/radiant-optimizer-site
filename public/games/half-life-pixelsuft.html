What it is

The page identifies an Xash3D Emscripten port of Half-Life. Included game content and a usable session were not confirmed, and original game data may be required.

What you need

  • A legally owned copy of Half-Life for any required data
  • A desktop browser
  • The project's own notes on which content is bundled

How to open it

  1. Open the source destination from this page.
  2. Read the setup page for data requirements.
  3. Load your own files only if the project asks for them.

Before you click

We link to the original destination only and we do not host or provide game files. If the project asks for data, use files from a game you legally own. Never bypass a certificate warning and never install an unfamiliar executable to play a browser game.

Diddy Kong Racing

The N64 adventure racer with cars, planes and hovercraft.

Open project page ↗ Back to the original list

Verification status

Checked Oct 11, 2026; HTTP response 200. Gameplay not tested.

Project status / evidence: Clean-room browser build of the N64 adventure racer, hosted by Decomp Games. Three vehicle types included.

What it is

Diddy Kong Racing is Rare's 1997 N64 racer, and it mixes racing with a single-player adventure that has an explorable overworld and boss races. It also uses three vehicle types, cars, planes and hovercraft, which the courses switch between mid-race. This build runs from the community decompilation of the N64 original.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser with WebGL
  • A gamepad or keyboard
  • A modern browser, plus time for the overworld to load

How to open it

  1. Open the Diddy Kong Racing build on Decomp Games.
  2. Wait for the loader.
  3. Check the control notes, then start the adventure mode rather than a single race.

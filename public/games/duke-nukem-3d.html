Duke Nukem 3D

The 1996 shooter running from its DOS build in the browser.

Open the original project ↗ Back to directory

Runs the 1996 DOS build through js-dos browser emulation.

What it is

Duke Nukem 3D runs here through js-dos, a browser DOS environment. The 1996 executable boots in the tab, so the interactive scenery, the weapon set and the level design behave as they did on period hardware. It was one of the first shooters to build a genuinely city-like environment rather than corridors.

What you need

  • A desktop browser
  • A keyboard and mouse
  • A click on the canvas to capture input

How to open it

  1. Open the Duke Nukem 3D page on js-dos.
  2. Click the screen to lock the mouse.
  3. Use the in-game menu for controls, sound and difficulty.

Before you click

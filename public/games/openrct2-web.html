OpenRCT2

The open-source RollerCoaster Tycoon 2 engine, running in a browser tab.

Open the original project ↗ Back to directory

The engine is open source but expects original RollerCoaster Tycoon 2 data that you supply yourself.

What it is

OpenRCT2 is an open-source reimplementation of RollerCoaster Tycoon 2. The engine is free, but it deliberately does not ship the original art and sound, so you must supply the data files from a copy you own. That makes it the one entry in this library that genuinely requires a purchase before it will run.

What you need

  • A legally owned copy of RollerCoaster Tycoon 2
  • A desktop browser with enough local storage for the data files
  • The project's own instructions for uploading game data

How to open it

  1. Read the site's notes on which game files are required.
  2. Upload data from a copy you own.
  3. Start a scenario once the assets are loaded.

Before you click

We link to the original destination only and we do not host or provide game files. If the project asks for data, use files from a game you legally own. Never bypass a certificate warning and never install an unfamiliar executable to play a browser game.

Sonic the Hedgehog 2

The Mega Drive speed platformer, rebuilt to run in a browser.

Open project page ↗ Back to the original list

Verification status

Checked Oct 11, 2026; HTTP response 200. Gameplay not tested.

Project status / evidence: Clean-room browser build of the 1992 Mega Drive original, hosted by Decomp Games.

What it is

Sonic the Hedgehog 2 is the 1992 Mega Drive sequel that introduced the Spin Dash and Tails as a companion. It also added a split-screen two-player versus mode, which the first game did not have. This build runs from the community decompilation of the Mega Drive original rather than a ROM emulator.

Requirement

No extra files listed No extra game files or installer are listed as requirements. This does not establish destination availability or gameplay.

What you need

  • A desktop browser
  • A keyboard or gamepad for the Spin Dash timing
  • A modern browser

How to open it

  1. Open the Sonic 2 build on Decomp Games.
  2. Wait for the loader.
  3. Check the controls, then pick a zone or start the two-player versus mode.

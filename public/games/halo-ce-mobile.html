Halo CE Mobile

A Halo browser project aimed at mobile devices that needs your own disc data.

Open the original project ↗ Back to the original list

The project asks for your own disc data. No game files are provided here.

What it is

This project targets mobile browsers and asks for an Xbox Halo CE disc image that you supply yourself. Browser access does not include that disc data.

What you need

  • A legally owned Xbox Halo CE ISO or XISO that you prepare yourself
  • A modern mobile browser with enough memory
  • Touch controls, or a paired controller

How to open it

  1. Read the project's instructions for preparing the disc image.
  2. Open the source destination on your device.
  3. Load your own data when the project asks for it.
  4. Check the project's supported-browser list if graphics fail to start.

Before you click

We link to the original destination only and we do not host or provide game files. If the project asks for data, use files from a game you legally own. Never bypass a certificate warning and never install an unfamiliar executable to play a browser game.

Half-Life / CS 1.6 (WebXash)

The webXash engine project for compatible Half-Life and Counter-Strike data.

Open the original project ↗ Back to directory

The destination identifies WebXash. Check the setup screen for data requirements.

What it is

The destination identifies the webXash engine, which runs compatible Half-Life and Counter-Strike data in the browser. Check the current setup screen for what data it expects.

What you need

  • Legally owned Half-Life or Counter-Strike data if the project asks for it
  • A desktop browser
  • The project's own setup instructions

How to open it

  1. Open the source destination from this page.
  2. Read the setup screen for data requirements and available demos.
  3. Supply your own data only where the project documents it.

Before you click

We link to the original destination only and we do not host or provide game files. If the project asks for data, use files from a game you legally own. Never bypass a certificate warning and never install an unfamiliar executable to play a browser game.

F-Zero X

The fast, futuristic N64 racer, rebuilt for the browser.

Open the original project ↗ Back to the original list

Clean-room browser build of the N64 racer, hosted by Decomp Games. Includes the randomly generated X Cup.

What it is

F-Zero X is Nintendo's 1998 anti-gravity racer, and it is unusual for running 30 machines on track at once at a locked frame rate. It also includes the X Cup, which generates its tracks randomly, and a Death Race mode with no track at all. This build runs from the community decompilation of the N64 original.

What you need

  • A desktop browser with WebGL
  • A gamepad or keyboard, since precise steering matters
  • A modern browser

How to open it

  1. Open the F-Zero X build on Decomp Games.
  2. Wait for the loader.
  3. Check the controls, then start a cup or try the randomly generated X Cup.

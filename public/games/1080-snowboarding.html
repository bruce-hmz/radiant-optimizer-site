1080° Snowboarding

The N64 snowboarding game, rebuilt to run in a browser from the clean-room pipeline.

Open the original project ↗ Back to directory

Clean-room browser build of the N64 original, hosted by Decomp Games. A race plays start to finish; assets are regenerated.

What it is

1080° Snowboarding is Nintendo's 1998 N64 snowboarding game, split between downhill races and trick runs across six courses, with scoring that rewards both speed and style. This build runs the retail program through EmulatorJS with textures, images and audio regenerated by the clean-room pipeline, so it ships no original ROM, textures or audio. The regenerated art deliberately differs from the retail release.

What you need

  • A desktop browser with WebGL
  • A keyboard or gamepad, because the trick runs need more than two inputs
  • A tolerance for regenerated textures and a substitute soundtrack

How to open it

  1. Open the 1080° Snowboarding build on Decomp Games.
  2. Tap or press a key once, since sound only starts after your first input.
  3. Pick a course and a mode; touch controls are still being rolled out, so use a keyboard or pad.
